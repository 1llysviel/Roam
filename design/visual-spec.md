# 视觉规格（v0.1 初始基准）

> 用户尚未提供参考图。本规格是**原创的初始设计方向**，待同行看过后调整，不代表已获确认。
> 方案中指定的 `frontend-design` 与 `web-design-reviewer` 两个技能位于维护者本机（`~/.agents/...`），云端构建环境中不可用；本版按同样的闭环手工执行：规格 → 实现 → 同视口截图 → 差异清单 → 修正 → 复验（见 review-log.md）。

## 方向

旅行手册：浅色纸感底、深色正文、单一强调色（邮筒红）、地图占主要面积、日期清晰。状态用「图标 + 文字」表达，不只靠颜色。核实统计放在「总览」，不占据主浏览空间。

## 构图

- **桌面（≥861 px）**：顶栏（标题 + 日期范围 + 视图标签）→ 15 天日期条（等分铺满）→ 初稿提示条 → 左侧当天卡片 / 右侧粘性地图；点地点弹出地点详情浮层；来源详情在卡片内展开。
- **手机（≤860 px，含 768 平板）**：顶栏压缩（隐藏城市列表）→ 横向滚动日期条（当前日期自动居中）→「行程 / 地图」切换 → 地图模式下底部地点详情抽屉；来源与核实时间在二级展开中。
- **卡片对齐**：时间列 + 正文列；标题基线统一；状态徽章 24 px 高；按钮 36 px（手机 44 px）；长英文地名换行（`overflow-wrap: anywhere`），不截断。

## 可访问性

正文对比度 ≥ 4.5:1（muted 文字在纸底上约 5.2:1）；`:focus-visible` 3 px 蓝色描边；尊重 `prefers-reduced-motion`；地图标记有 `title/alt`，可键盘聚焦。

## 截图对照方法

`npm run build && npm run shots`：固定 1440 / 768 / 390 / 375 视口、固定数据、`deviceScaleFactor: 1`、浏览器时区设为洛杉矶（验证纯日期不偏移），用**本地固定测试瓦片**替代 OSM 底图，等待字体就绪。脚本同时检测横向溢出与关键文字截断。`--tiles=fail` 模拟底图不可用。真实底图需人工另看。
